# Glossary — Mobile Money Nano-Credit

Educational terminology for **nano-credit, wallet overdrafts, and mobile micro-loans**. Definitions are industry-oriented; lender and operator labels vary.

## Core Terms

| Term | Definition |
|------|------------|
| **Nano-credit** | A very small, short-term digital loan, usually paid into a mobile wallet |
| **Wallet overdraft** | Permission to complete a payment beyond the available balance, recovered later |
| **Credit limit** | Maximum amount a customer can borrow at a given time |
| **Limit graduation** | Raising a customer's limit after on-time repayments |
| **Scorecard** | Rules or a model that turn customer data into a risk band or limit |
| **Eligibility rule** | A hard condition, such as minimum account age, checked before scoring |
| **Disbursement** | Paying loan principal into the customer's wallet |
| **Auto-sweep** | Automatic repayment taken from new money arriving in the wallet |
| **Partial repayment** | Paying back part of the amount owed before the due date |
| **Facility fee** | A fixed charge for taking the loan, common in nano-credit |
| **Days past due (DPD)** | How many days a loan is overdue |
| **Default** | A loan unpaid beyond the agreed overdue threshold |
| **Write-off** | Removing an unrecoverable loan from the active book |
| **Lending partner** | The licensed bank or lender that funds and holds the loans |
| **Loan ledger** | Records of principal, fees, repayments, and status per loan |
